# miniverse

상자, 원기둥, 원뿔, 공을 쌓아 만든 작은 3D 장소들을 웹 브라우저에서 걸어 다니는 사이트입니다.
모델 파일과 음원 파일 없이 [three.js](https://threejs.org/)와 Web Audio만으로 그리고 소리를 냅니다.

## 장소

| 장소 | 폴더 | 상태 |
| --- | --- | --- |
| 🏫 학교 | [`school/`](school/) | 완성 |
| 🏖️ 바닷가 | `beach/` | 준비 중 |

## 여는 방법

- 맨 위 `index.html`을 브라우저로 열고 장소를 고르거나, 장소 폴더의 `index.html`을 바로 엽니다.
- three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작법

- **컴퓨터:** W·↑ 앞으로, S·↓ 뒤로, A·D·←·→ 방향 틀기, Shift 달리기, Space 점프, 드래그로 둘러보기
- **휴대폰:** 왼쪽 아래 조이스틱으로 걷기, 오른쪽 아래 단추로 달리기·점프
- 화면을 처음 누르면 소리가 나고, 왼쪽 위 단추로 소리를 끄고 켭니다.

## 새 장소 추가하기

1. 장소 이름으로 폴더를 만들고 그 안에 `index.html` 하나를 둡니다.
2. 맨 위 `index.html`의 장소 목록과 이 README의 표에 추가합니다.
